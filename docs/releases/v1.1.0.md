## Payload Runner v1.1.0

本次版本将请求格式化、编辑和 `§` 注入点标记整合到同一个编辑器，重点修复选区漂移、清除标记误删字符，以及 UTF-8 标记兼容问题。

### 新功能

- 单一请求标记编辑器，提供“格式化显示”开关，不需要在原生页和标记页之间切换。
- JSON 和结构型 XML 缩进显示；格式化仅改变显示，不改原始请求的换行、空格和其他字节。
- 在格式化后的字段值、数组和子树上直接选中、编辑和添加 `§内容§` 标记。
- 支持标记高亮、右键菜单、空注入点，以及成对添加/清除标记的撤销和重做。
- 字体采用插件页签的字体和字号，使用普通字重；语法颜色适配浅色、深色主题。

### 修复与保护

- 选区、标记和清除统一映射回原文，避免 Swing 换行序列化导致的位置漂移和误删。
- 粘贴采用纯文本处理，保留实际粘贴内容的 CRLF 等换行，不导入富文本字体。
- 格式化开关不会修改请求，也不占用撤销历史；只选择虚拟缩进时拒绝标记和删除。
- 正确区分 UTF-8 字符中的普通字节和旧版单字节 `§`，避免普通中文、外文和 emoji 被误识别为注入点。
- 兼容历史 `§` 和临时 `~PR~` 标记；运行时仅替换当前注入点，并移除其他注入点的定界符。
- XML 格式化禁用 DTD、外部实体和外部资源；过大、过深或无法安全格式化的内容原样显示。

### 安装与使用

1. 下载本页附件 `payload-runner-burp.jar`，不要将源码 ZIP 当作插件加载。
2. 在 Burp 的 `Extensions → Installed` 中移除旧版本，再添加新的 Java 插件 JAR。
3. 将授权测试请求发送到 Payload Runner，选择字段值并点击“标记选中(§)”。
4. 如需手动编辑，编辑后点击“应用报文修改”，再执行测试。

快捷键：`Ctrl/Cmd+B` 添加标记，`Ctrl/Cmd+Shift+B` 清除标记，`Ctrl/Cmd+Z` 撤销，`Ctrl/Cmd+Shift+Z` 重做，`Ctrl/Cmd+Enter` 应用修改。

### 验证范围与已知限制

- 标记专项覆盖 64 组格式化映射、48 组换行/选区完整性场景，以及 JSON/XML 编辑、粘贴、重复值、UTF-8、虚拟缩进、撤销/重做和高亮绘制。
- CI 执行标记专项、全量 smoke test 和 JAR 构建。发布前本地 JAR 构建成功；本地全量测试的网络部分受运行环境限制，以关联 CI 的实际结果为准。
- 尚未在真实 Burp 中进行本版本的手动交互验收；自动化检查不代表已完成 Burp 实机验证。
- 这是自定义编辑器，不是直接复用 Intruder/Repeater 的原生编辑器；不能保证与 BP 私有语法配色逐项一致，进一步原生化样式不属于本次发布。
- 当前格式化支持 JSON 与结构型 XML；HTML/CSS/JavaScript、XML 混合内容、`xml:space="preserve"`、DTD 和不完整内容原样显示。
- 请求格式化预算为 512 KiB、显示最多 2 Mi 字符，并限制嵌套深度。非 UTF-8 数据可以保留原始字节，但不保证可读显示。
